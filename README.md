# سبزینه | دستیار نگهداری گیاهان

اپلیکیشن Android Native با Kotlin برای ثبت گیاهان آپارتمانی و یادآوری زمان بررسی آبیاری.

## امکانات نسخه فعلی

- داشبورد تعداد گیاهان و گیاهان نیازمند بررسی
- ثبت، ویرایش و حذف گیاه
- محل نگهداری و فاصله قابل تنظیم بررسی آبیاری
- صفحه جزئیات هر گیاه و ثبت زمان آخرین آبیاری
- راهنمای اولیه پتوس، سانسوریا، مونسترا، زاموفیلیا، اسپاتی‌فیلوم و کاکتوس
- یادآوری محلی با اعلان اندروید و انتخاب ساعت یادآوری
- بازیابی یادآورها بعد از راه‌اندازی مجدد گوشی
- ذخیره‌سازی آفلاین روی خود دستگاه؛ بدون حساب کاربری و بدون ارسال اطلاعات به سرور

> فاصله‌های آبیاری در راهنما تخمینی هستند. شرایط واقعی خاک، فصل، نور، دما و اندازه گلدان باید ملاک تصمیم باشد.

## ساخت APK با GitHub Actions

1. یک مخزن جدید در GitHub بساز.
2. تمام فایل‌های این پروژه را در ریشه مخزن قرار بده و روی شاخه `main` پوش کن.
3. وارد تب **Actions** شو.
4. گردش‌کار **Build Android APK** را باز کن و در صورت نیاز روی **Run workflow** بزن.
5. بعد از موفق شدن اجرا، از بخش **Artifacts** فایل `sabzineh-debug-apk` را دانلود کن.
6. فایل ZIP دانلودشده را باز کن؛ داخل آن `app-debug.apk` قرار دارد.

هر بار که روی `main` یا `master` پوش انجام شود نیز APK به‌صورت خودکار ساخته می‌شود.

## نسخه‌ها

این پروژه از Kotlin داخلی AGP 9 استفاده می‌کند؛ افزونه قدیمی `org.jetbrains.kotlin.android` عمداً حذف شده است. مقدار هدف JVM از `compileOptions` اندروید به ارث می‌رسد.

- Android Gradle Plugin: 9.4.0
- Gradle: 9.6.0
- Kotlin: Built-in Kotlin provided by Android Gradle Plugin 9.4.0
- JDK: 17
- compileSdk / targetSdk: 36
- minSdk: 24 (Android 7.0)

## باز کردن در Android Studio

پوشه پروژه را با Android Studio باز کن و اجازه بده Gradle Sync انجام شود. برای build محلی باید JDK 17 و Android SDK Platform 36 نصب باشد. در CI از Gradle نصب‌شده توسط GitHub Actions استفاده می‌شود.

## نکته انتشار و تبلیغات

این خروجی، **debug APK** است و برای تست و نصب مستقیم ساخته می‌شود؛ برای انتشار رسمی باید نسخه release را با کلید امضای اختصاصی امضا کنی و ترجیحاً AAB بسازی.

در این نسخه هیچ SDK تبلیغاتی یا AdMob قرار داده نشده است. پیش از افزودن شبکه تبلیغاتی، شرایط جغرافیایی و قوانین ناشر آن شبکه را بررسی کن. اطلاعات گیاهان در نسخه فعلی آفلاین می‌ماند.
